# Vesta PMO — نسخهٔ آزمایشی

نسخهٔ آفلاین و دمو برای ارزیابی رابط و گردش‌کارهای وِستا PMO.

- هر کاربر آزمایشی فقط داده‌های محلی همین مرورگر را دارد.
- ورود و نقش‌ها برای نمایش رابط هستند و احراز هویت یا مجوزدهی سمت سرور ندارند.
- Firebase متصل نیست و اطلاعات بین دستگاه‌ها همگام‌سازی نمی‌شوند.
- لطفاً اطلاعات واقعی افراد، کارکنان یا پروژه‌ها را وارد نکنید.
- فایل `index.html` مستقل است و برای اجرای هسته به وابستگی خارجی نیاز ندارد.
